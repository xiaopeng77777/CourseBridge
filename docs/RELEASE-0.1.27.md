# 0.1.27 · 2026-11-06 · Public Preview

本次公开更新合并此前本地 0.1.26 的个人空间入口与图片题能力，并补充图片选项识别修复。桌面端、浏览器扩展、构建和测试源码同步公开。

## 图片题

- 按实际选项行收集题干与选项中的图片、SVG、Canvas 和 CSS 背景图，覆盖选项字母标签与图片分离的结构。
- 不把可见图片上的 aria-hidden 当成视觉隐藏；实际隐藏或未加载成功的图片仍会提示。
- 保持本地优先；当前策略允许且已启用 DeepSeek 时，可用 Flash 分析图片。长图生成概览与细节分段，图片和选项索引绑定。
- 图片题不消耗言溪的纯文字查询；只读取到 A/B/C/D 时也不会发起无效文字查询。关闭图片分析、模型不支持、超限或加载失败时保留人工处理。
- 网络答案按原有设置保存来源及未核验标记；图片分析会产生额外输入 Token，具体费用由 DeepSeek 结算。

## 浏览器入口

课程浏览器从关闭状态打开时进入课程平台个人空间，不再恢复历史考试或课程列表；浏览器已打开时保留当前页面。登录仍在课程平台登录页面手动完成。

## 发行与隐私

- 保留原桥形标志和浅色界面；不新增第三方 OCR、运行依赖、隐藏用量试验或监控上报。
- 最近状态仅增加图片协议、题目数、图片数与失败数用于排错，不记录图片内容、原始图片网址或额外使用统计。
- 从公开源码白名单构建干净安装包，不带个人题库、账号、API Key、浏览器资料或真实试卷。
- 安装包名称和卸载项版本跟随项目版本，提供 SHA-256 校验。

图片读取只面向专用课程浏览器中的对应题目元素，不截取整屏，不向 AI 发送原始图片网址、Cookie 或登录凭证。详见[隐私说明](PRIVACY.md)、[来源与致谢](ATTRIBUTION.md)及[图片题说明](图片题与默认入口.md)。

## 验证和限制

使用合成页面与模拟 API 验证图片读取、长图切分、MV3 插件通信、选项填写、缺失图片保护及默认入口；未使用真实查题额度进行发行测试。实际反馈中的图片选项问题已由用户更新后确认恢复，但不构成任意课程、题型或答案正确率的保证。

整卷预览仍只读；未知交互题型、输入拒绝和无法确认完成时需要人工核对。更新前保存答案并退出课程浏览器及课桥。当前仍通过 Releases 手动下载安装，未实现软件内自动更新。完整检查记录见[发行验证](VALIDATION.md)。
