# 使用说明

## 安装与连接

从[官方仓库 Releases](https://github.com/xiaopeng77777/CourseBridge/releases)下载安装包；核对版本与 `SHA256SUMS.txt`。Windows PowerShell 可用 `Get-FileHash -Algorithm SHA256 -LiteralPath '你的安装包路径'` 查看散列值。当前安装包未签名，下载和校验来源需一致。

安装后点击“打开课程浏览器”。首次下载组件需要网络，完成后自动加载插件并配对；不必安装普通 Chrome，也不应把课桥资料目录当作普通浏览器资料目录使用。在学习通官方页面手动扫码或登录，进入章节，再回到课桥点击开始任务。

登录后又回二维码时，先暂停任务，从课程浏览器的新标签页打开 `https://i.chaoxing.com/` 重新登录。旧二维码会过期，多个登录页也可能互相干扰；不要反复使用旧页面。普通浏览器可登录并不等于专用浏览器已登录，两者资料隔离。课桥不会复制普通浏览器 Cookie。

## 题库、查题与费用

公开安装包不含第三方历史题库。可在“我的题库”导入自己编写或有权使用的 JSON / CSV，格式见 [`examples/question-bank.json`](../examples/question-bank.json)。也可以新建题目，或让插件收集当前可见题目；收集不等于获得答案。

查题策略始终先本地，再按选项使用言溪或 DeepSeek。到“查题服务”填写自己的凭证，启用对应来源，再到任务设置开启自动填写；自动提交是另一个独立开关，默认关闭。没有答案时显示等待原因，是否保留测验继续课程由设置决定；视频弹题和正式考试不会因这个设置被任意跳过。

言溪次数由其接口返回，DeepSeek 余额和费用由其平台结算。界面中“本次请求 / Token”是会话内反馈，重启清零，不是账单、费用承诺或桌面统计文件。失败请求是否计费应向服务商核对。凭证不要发送给项目维护者。

在线答案自动保存可关闭。保存后保留来源，并标记未核验；AI 结果可能错误，不应把“已填入”当作“已答对”。结合专业的文本题可填写自己的专业，但不要填写身份证号等无关个人信息。

## 数据保存与升级

- 安装版：`%LOCALAPPDATA%\CourseBridge\data`。
- 源码运行：项目下 `data/`。
- 开发 / 测试可用 `COURSEBRIDGE_DATA_DIR` 指定独立目录。

其中包含本地设置、题库、系统加密的服务凭证、课程浏览器资料、已打开课程页面列表、字体缓存及最近状态文件。不要把整个目录公开上传或发给其他人。题库备份只导出题库内容，不包含服务凭证；题目本身仍可能含个人资料，应先核对。

0.1.25 使用安装版固定资料目录，不会自动合并旧便携版或朋友测试版的数据。旧版题库可在旧软件里导出后导入；凭证需手动重新配置。卸载默认保留个人资料。需要彻底清除时先关闭软件、做好备份，再手动删除上述目录。

目前从 Releases 手动下载更新。更新前保存未完成输入，关闭课程浏览器并退出课桥；不要在考试进行中安装新版本。软件不会自动迁移、删除旧的特殊测试版导出文件；如之前生成过，应在自己的电脑上另行处理。

## 浏览器组件与许可

课桥的公开安装包不重新分发 Chrome for Testing 二进制。首次使用时，经你点击确认，通过固定版本的 Playwright 下载其匹配的浏览器组件；下载来源由上游 Playwright 管理，通常为 Microsoft / Google 官方分发主机。课桥没有自己的浏览器下载中转服务器。

组件与课桥源码适用不同条款：[Chrome for Testing 官方说明](https://github.com/GoogleChromeLabs/chrome-for-testing)、[Google Chrome 条款](https://www.google.com/chrome/terms/)、[Google 服务条款](https://policies.google.com/terms)。浏览器中的 `chrome://credits` 可查看其第三方组件声明；不能把管理脚本仓库的许可当作浏览器全部内容的许可。

首次下载失败可再次点击打开课程浏览器重试。公司 / 校园网络的代理和下载限制可能导致失败；课桥不会关闭系统证书校验或替你改变全局网络设置。浏览器下载后不会随普通 Chrome 自动更新，应随课桥依赖版本升级维护。

## 电源与页面限制

防自动睡眠仅在设置开启、接通电源、任务运行且课程已连接时生效。它不修改 Windows 全局息屏时间，也不覆盖合盖、主动睡眠或低电量策略。视频播放请求可能阻止系统息屏；本版没有承诺最小化或后台播放仍能满足课程完成条件。

平台要求观看比例、禁止拖动或要求前台播放时，以官方规则为准。课桥不会伪造任务点完成、修改服务端学习时长或替用户绕过验证。出现验证码、输入失败或无法确认完成时应回到网页人工处理。

## 已知兼容性边界

整卷预览只读；页面可能分批加载试题。多选状态、富文本和提交确认在本地模拟场景测试过，但不能保证所有真实考试版本兼容。文本输入会保护已有正文，回读长度和内容；若显示未完成，应暂停自动任务并人工核对，而不是反复覆盖。

反馈时只提供去除参数后的页面路径、软件版本、浏览器版本与错误提示。不要附真实试题、二维码、学号或整个资料目录。
