# 隐私与网络行为

适用于 0.1.25。课桥没有自己的云账户、分析服务器或广告服务。应用不内置维护者的言溪凭证、API Key 或学习通登录信息。

## 特殊测试功能的移除

0.1.24 曾有独立的用量试验专版。0.1.25 不包含其 `usage-study` 模块、后台试验接线、桌面 JSON / CSV / JSONL 自动统计导出或监控上报；不是隐藏入口或仅关闭开关，而是公开构建输入中不存在这些实现。后续版本也不应重新引入。

本地活动记录、最近状态文件、账户剩余次数与当前会话 Token 显示仍存在，作用和保存范围如下。这些正常功能不等于后台费用对比实验，也不会发送给项目维护者。

## 本机保存的内容

| 内容 | 用途与位置 |
| --- | --- |
| 本地题库 / 收集的题干与选项 | 本机匹配、编辑和导出；未确认答案标记待补充 |
| `settings.json` | 任务设置和本机配对码；重启后任务保持暂停 |
| 言溪 / DeepSeek 配置 | 使用 Electron `safeStorage` 系统加密；系统加密不可用时凭证仅保留在内存 |
| 课程浏览器资料与页面列表 | 独立浏览器登录状态和下次打开课程；可能包含个人身份和课程 URL |
| 字体缓存 | 页面字体映射，帮助本机识别文字 |
| `last-status.json` | 最近课程 / 框架状态用于排错；去除配对码、完整 URL 参数和题目内容，但课程标题、域名与页面路径仍可能存在 |
| 活动记录和服务会话用量 | 近期本机操作反馈；会话请求 / Token 非长期桌面用量统计 |

安装版目录为 `%LOCALAPPDATA%\CourseBridge\data`；源码版为项目内 `data/`。不要公开整个目录、课程页面 URL、浏览器 Cookie 或加密凭证文件。系统加密保护并不能代替操作系统账号和磁盘安全。

## 数据何时联网

- 桌面端和插件通过 `127.0.0.1:17328` 与随机配对码通信，服务只绑定回环地址，不对局域网公开题库。课程内容从浏览器流向本地桌面端。
- 你配置、启用并通过策略选择言溪后，缺失题目会发送到言溪查题服务，凭证与额度请求直接发给该服务。
- 你配置、启用并选择 DeepSeek 后，题目、选项、所需答案格式及你填写的专业等上下文会发送到 DeepSeek 官方 API；完整请求以公开代码为准。服务方可能处理和保存请求，适用其数据政策。
- 首次浏览器下载会联系 Playwright 上游分发主机；打开帮助链接会启动官网页面。
- 学习通页面和下载的浏览器组件有自己的联网与数据行为，不能把“课桥无分析上报”理解为第三方网页或浏览器绝无网络请求。

只想本地处理时，选“仅本地题库”，关闭在线服务与题目收集等不需要的功能。关闭在线答案保存会阻止后续网络答案自动进入本地库，不会自动删除此前保存的题目。

## 分享与清除

分享软件请使用干净的安装包或仓库源码，不要复制正在使用的安装目录和资料目录。导出的题库仍可能包含题目版权和个人资料，应自行确认分享权限。

卸载默认保留数据。彻底清除前退出课桥和课程浏览器，备份有权保留的资料后删除数据目录；旧特殊测试版此前生成的桌面统计文件需要你自行另行删除，本版不会扫描桌面并替你删除文件。
