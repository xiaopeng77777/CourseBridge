# 0.1.27：个人空间入口与图片题

专用浏览器从关闭状态重新打开时，进入 `https://i.mooc.chaoxing.com/space/index`，不读取旧的考试 / 课程页面列表。已打开浏览器时点击“打开课程浏览器”仍回到当前课程，避免打断学习；内部插件更新所需的显式页面恢复仍保留。登录过期时由用户在学习通官方页面完成扫码，课桥不代替用户登录。

## 图片题处理

题干和选项中的图片、内嵌 SVG、Canvas 与对应题目 / 选项独立绑定。只有字母、没有文字的图片选项不会因文字为空被丢弃，也不会把 A/B 当成图片内容发给文字题库。

本地保存过的同题、同图片选项答案仍先匹配。需要看图时，使用已配置、启用且被当前策略选中的 DeepSeek Flash；图片题不调用不支持该图形匹配路径的言溪接口，避免消耗无效查询次数。选择“仅本地”或“本地 → 言溪”时，缺失图片题会说明需要手动补充或启用 DeepSeek，不会擅自启用其他服务。

在“任务设置 → 题目处理”可关闭“分析题干与选项图片”。这个开关不代替 DeepSeek 账号启用、自动填写和查题策略开关；尚未配置服务时不会发起请求。选择不支持图片的 Pro 模型会提示切换到 Flash，不会自动改模型。

桌面端只读取专用课程浏览器中实际存在、标识匹配的题目图片，优先读取原始像素，必要时截取单个图片元素。不会截取整屏，也不把原始图片网址、Cookie 或登录凭证发送给 AI。长图生成整体概览与有重叠的细节分段，避免整张缩小后文字和连线无法辨认。

**图像会发送到你启用的 DeepSeek 官方 API，并计入 Token；长图分段通常比纯文字消耗更多输入 Token。** 首次请求结果会缓存；暂停会阻止准备中的图片继续发起收费分析。图片加载失败、大小 / 数量超限或模型无法确定时，不会随机选答案或循环收费重试，保留人工核对。手动点击查题重试可能产生新的 API 用量。

图片身份标记与选项顺序一起参与匹配。若允许在线答案自动存回，保存的是图片指纹与对应选项答案，保留 AI / 未核验来源；不把图片二进制或浏览器凭证存进题库备份。图片 URL、内容或选项变化后可能需要重新分析。

## 兼容范围

支持普通文字选择 / 判断题、常见图片题干 / 图片选项、图文混排，以及已有的填空 / 简答 / 论述题输入路径。图形关系或公式题需要模型理解，文字 OCR 本身并不足够；这不是任意学校、任意题型或正确率的保证。

拖拽配对、排序、绘图、文件提交、复杂交互和页面未加载完整等情况仍可能需要针对实例适配。正式试卷的整卷预览仍保留只读保护。本次验证使用合成图片、模拟 API 和独立浏览器，不消耗真实账号额度，也没有自动提交用户当前作业。

实现使用现有 Electron 原生图像能力和 Playwright，不新增第三方 OCR 服务、运行依赖或监控。DeepSeek 图片输入能力与限制按[官方 Vision 文档](https://api-docs.deepseek.com/guides/vision/)核对（2026-11-06）。
