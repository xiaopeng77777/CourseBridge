如何收集和导入题目？

在课程浏览器打开具体章节测验，已识别的题目会进入“待补充”，同题干和同选项自动去重。不会从已选择的选项猜测正确答案。当前支持常见单选、多选结构。

支持 JSON 和 CSV 合并导入。Excel 文件请先另存为 UTF-8 CSV。CSV 表头可用“题目,答案,选项,题型”；多个答案或选项用 | 分隔，题型填“单选”或“多选”。留空答案可导入待补充题目。导入不同答案产生冲突时会暂停使用该题，等待核对。 

[
  { "question": "以下哪项是可再生能源？", "answers": ["太阳能"] },
  { "question": "待补充的题目", "options": ["选项一", "选项二"], "answers": [] }
]

先查本地，再按你的选择补充答案。在线服务独立提供，使用自己的账户与额度。

服务、费用与自动保存说明

DeepSeek 是独立第三方服务，与课桥无隶属或合作关系。调用费用由 DeepSeek 按你的 API 账户计费，使用课桥不附送额度。启用后会向官方接口发送需要分析的题干、选项和题型；结合专业的文本题还会发送你填写的专业背景。

AI 可能答错或无法确定答案；成功返回不代表正确。开启自动存回后，结果带来源与“未核验”标记保存，可供后续本地匹配，也会包含在你导出的题库备份中。可以在“在线未核验”筛选中检查并修正。

保存并验证只读取账户余额，不调用收费的答题接口。自动查题通常每题请求一次；有最低字数要求的文本题，字数不足或被截断时最多自动补写一次，可能增加一次 API 费用。仍不合格则停止，不随心跳重复收费重试；手动重试和更换模型可能产生新费用。

服务、费用与自动保存说明

课桥只提供可选的接口连接，不提供或出售言溪查题额度。账号、收费、可用次数及服务规则由言溪独立管理；使用课桥不代表获得言溪服务或额度。

启用且查题策略包含言溪时，仅在任务运行并开启自动填写时，将缺答案题目的题干、选项和题型发送至言溪。返回内容可能是 AI 生成的参考答案，不保证覆盖所有课程或答案正确。开启“在线答案自动存回本地”后，会保存来源和未核验标记，也会包含在个人题库导出中；关闭时仅供本次运行缓存使用。

重试会再次请求第三方接口，可能消耗你的额度。未配置或关闭时，课桥继续使用本地题库。
